# Screenshots

Empty on purpose. Every screenshot this directory held was captured before the UI
gained its **Trial results** tab, lost **Ask** and **Hypothesize**, and dropped the
"AI-native" tagline, so each one showed a tab bar, a banner and a header that no
longer exist. Shipping them would have misrepresented the interface to anyone
reading the README.

To take fresh ones:

```bash
vitiligo serve          # http://127.0.0.1:8765
```
